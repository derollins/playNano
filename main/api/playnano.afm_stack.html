playnano.afm_stack module¶

The AFMImageStack class, which holds an AFM video and everything done to it.

The module also builds the lookup tables of built-in steps that AFMImageStack.apply() and the processing pipeline use: FILTER_MAP, MASK_MAP, MASK_FILTERS_MAP, VIDEO_FILTER_MAP and STACK_EDIT_MAP.

class playnano.afm_stack.AFMImageStack(data: ndarray, pixel_size_nm: float, channel: str, file_path: Path, frame_metadata: list[dict[str, Any]] = None)[source]¶

Bases: object

An AFM video: frames, pixel size, per-frame metadata, results and provenance.

Usually made by load_data() or playnano.io.loader.load_afm_stack(), and changed by playnano.processing.pipeline.ProcessingPipeline and playnano.analysis.pipeline.AnalysisPipeline.

Parameters:

  • data (numpy.ndarray) – Frames, shape (n_frames, height, width), heights in nm. Stored as given, without copying.

  • pixel_size_nm (int or float) – Pixel size in nm, used when a frame has no frame_pixel_size_nm. Must be a positive Python int or float: NumPy numbers are rejected.

  • channel (str) – Channel name, for example "height_trace".

  • file_path (str or pathlib.Path) – File or folder the data came from. Stored as given; used for default output names.

  • frame_metadata (list of dict, optional) – One dict per frame, with keys from FRAME_METADATA_KEYS in playnano.utils.io_utils; other keys give a warning. A shorter list is padded with empty dicts. Timestamps are converted with playnano.utils.time_utils.normalize_timestamps(), and a frame without one gets "timestamp": None. Default is None (no metadata).

Examples

>>> import numpy as np
>>> from playnano.afm_stack import AFMImageStack
>>> data = np.zeros((3, 64, 64))
>>> stack = AFMImageStack(
...     data,
...     pixel_size_nm=2.0,
...     channel="height_trace",
...     file_path="demo.h5-jpk",
...     frame_metadata=[{"timestamp": 0.0}, {"timestamp": 0.5}],
... )
>>> stack.n_frames, stack.image_shape
(3, (64, 64))
>>> stack.get_frame_times()
[0.0, 0.5, 2.0]
property acquisition: dict[str, Any]¶

Settings of the whole recording, from the file’s header.

For example whether the scan was bidirectional, or the file version, depending on the format; empty if the reader found none. Stored in provenance["acquisition"], and kept when frames are removed.

apply(steps: list[str], **kwargs) → ndarray[source]¶

Apply processing steps by name, without recording provenance.

A quick way to process a stack interactively. For processing you can repeat and report, use playnano.processing.pipeline.ProcessingPipeline.

Each name is looked up in this order:

  1. "clear": forget the current mask;

  2. a mask generator (MASK_MAP), which sets the mask for later filters;

  3. a method of this class;

  4. a plugin registered under playnano.filters or playnano.video_processing;

  5. a built-in filter (FILTER_MAP); if a mask is set and the filter has a masked version (MASK_FILTERS_MAP), that version is used;

  6. a video filter (VIDEO_FILTER_MAP);

  7. a stack edit (STACK_EDIT_MAP), which also clears the mask.

Parameters:

  • steps (list of str) – Step names, applied in order, for example ["remove_plane", "mask_threshold", "row_median_align"].

  • **kwargs – Passed to every step. A step that does not accept them is called without any.

Returns:

The processed data, also stored in data.

Return type:

numpy.ndarray

Raises:

ValueError – If a step name is not found.

Notes

processed gets "raw" (if not already there) and a copy of the data after each step except "clear" and masks, keyed by step name, so a repeated step replaces its earlier copy. Masks are not stored. If a filter fails on a frame, that frame is left unchanged and a warning is logged; if a video filter fails, the step is skipped.

Examples

>>> import numpy as np
>>> from playnano.afm_stack import AFMImageStack
>>> yy, xx = np.mgrid[0:32, 0:32]
>>> data = np.stack([0.1 * xx + 0.05 * yy] * 2).astype(float)
>>> stack = AFMImageStack(data, 1.0, "height_trace", "demo.h5-jpk")
>>> out = stack.apply(["remove_plane"])
>>> sorted(stack.processed), bool(np.allclose(out, 0))
(['raw', 'remove_plane'], True)

export_analysis_log(path: str) → None[source]¶

Save the analysis results as a JSON file. Currently always raises an error.

It looks for results in an analysis_results attribute, which nothing in playNano sets, so it raises ValueError even after an analysis has run. To save results, pass the record returned by playnano.analysis.pipeline.AnalysisPipeline.run() to playnano.analysis.export.export_analysis_to_json().

Parameters:

path (str or pathlib.Path) – File to write. Its folder is created if missing.

Raises:

ValueError – If the stack has no analysis_results attribute, or it is empty.

export_processing_log(path: str) → None[source]¶

Save the environment and processing provenance as a JSON file.

The file holds {"environment": ..., "processing": {"steps": ..., "keys_by_name": ...}} from provenance.

Parameters:

path (str or pathlib.Path) – File to write. Its folder is created if missing; an existing file is overwritten.
